## T009 — existing safe probe executed on actual WindowsEnv

The already implemented `rust/src/bin/probe_workerw.rs` has a default read-only `--inspect`, explicit bounded legacy `--attach`, and an explicit bounded raised-desktop `--attach-modern` mode. In modern mode it creates only a **process-owned**, nonactivating, disabled layered `Progman` child; uses `SetLayeredWindowAttributes(alpha=255)` on **that** HWND; positions it immediately *below* `SHELLDLL_DefView`; reads back the parent and sibling order; and destroys/verifies its HWND within 10 seconds. It never sends undocumented `0x052C`, reparents/restyles an Explorer-owned window, modifies wallpaper/registry, or touches the C# reference.
